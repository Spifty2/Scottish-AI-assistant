Basic AI assistant running Gemma 4 on ollama.
User request processed by Gemma 4 given context and told to reply as a Scottish person.
Optional TTS read of output.
Optional internet search using online agent. search prompt generated by initial query.

When running in Docker Desktop, the app connects to Ollama on the host through
`host.docker.internal`. For another Ollama address, set `OLLAMA_API_URL` when
starting the container (for example, `-e OLLAMA_API_URL=http://host.docker.internal:11434/api/chat`).
